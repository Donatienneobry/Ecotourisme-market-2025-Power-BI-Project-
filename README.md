# Ecotourisme market Dashboard - Power BI Project

## Project Overview
This Power BI Dashboard provides an analytical view of Ecotourism performance across multiple dimensions<br /> 
🏆 Winning Combo<br />
🧓🏻 Age Group<br />
💹 Satisfaction Level<br />
This report was created to familiarize myself with Power BI.

---

## Objectives
This dashboard aims to identify the optimal combination of the following factors that encourages visitors to return to a tourist site:
— Type of visit (solo, group, couple, family, etc.)<br />
— Purpose of stay (photography, relaxation, adventure, wildlife study, etc.)<br />
— Type of site (mountain, forest, lake, coast, etc.)<br />

---

## Key Insights
Key Insights
- The analysis covers 5 types of visits, 5 types of sites, and 5 purposes of stay, for a total of 2,400 visits.
- The best “winning combos” (Top 5) generally combine solo or group stays with relaxation, adventure or photography on sites such as lakes, forests or coastal areas, and show a strong intention to return.
- Visitors with higher eco‑education and satisfaction levels contribute more to the segments with high revisit intent.

## Power BI Skills Demonstrated
- Data cleaning, transformation and modeling (visitors, sites, visit purposes, return intent).
- Creation of DAX measures to calculate the volume of return intent and identify the Top 5 most effective combinations.
- Design of an immersive layout with background image, KPIs, slicers and interactive visuals centered on the concept of “winning combos”.
---

## Dashboard Examples
- Overview of KPIs: number of reviews, number of visit types and site types, average eco‑rating, average eco‑education level.
- Top 5 winning combinations (visit type / purpose / site type) by positive return intent.
- Segment analysis (age groups, satisfaction levels) via slicers directly impacting the winning combos and average indicators.

---

## Business Impact
- Help sustainable tourism stakeholders target visitor profiles and site types with the highest revisit potential.
- Support marketing and planning decisions (offer design, communication, focus on specific sites) around the most attractive experience combinations.

## Objectifs
1. Ce dashboard vise à identifier la combinaison idéale des facteurs suivants : 
— type de visite (solo, groupe…),<br /> 
— objectif du séjour (photographie, relaxation…),<br /> 
— type de site (montagne, forêt…),<br />
qui incite les visiteurs à revenir sur un site touristique.
2. Identifier les indicateurs clés qui peuvent faire varier cette combinaison.

## Key Insights
- L’analyse couvre 5 types de visites, 5 types de sites, 5 objectifs de séjour, pour 2400 visites.
- Les meilleures “winning combos” (Top 5) combinent généralement séjour en groupe ou en solo avec relaxation, aventure ou photographie, sur des sites de type lac, forêt ou côte, et affichent une forte intention de retour.​
- Les visiteurs présentant une meilleure éducation éco et une satisfaction plus élevée contribuent davantage aux segments à forte intention de revisite.​
